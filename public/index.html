Say what you need to do. TaskPilot plans the day.

Write a normal sentence like "finish my DSA assignment, practice coding for 2 hours and meeting at 4 PM". TaskPilot creates the tasks, builds a schedule and tells you when two things overlap.

Example conversation

I have to finish my DSA assignment, practice coding for 2 hours, and attend a meeting at 4 PM.
I created three tasks and put the meeting at 16:00. Your coding practice has no time yet, want me to suggest a free slot?

Understands normal language

Several tasks in one message, with priorities, deadlines and durations picked out for you.

Does real actions

The assistant calls backend tools that save to a database. It is not just a chatbot.

Catches conflicts

Overlapping tasks are flagged and the planner suggests free slots you can apply in one click.

Has an MCP server

The same tools are available to MCP clients over Streamable HTTP at /mcp.

Honest note: the Alexa+ experience in this project is a simulation inside the web app. The MCP server is real, but nothing here is connected to a real Alexa+ device or service.
